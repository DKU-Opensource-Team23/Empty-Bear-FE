# :bear: 비었곰 프로젝트 README
### 1. 프로젝트 소개
비었곰(EmptyBear)은 학생들이 빈 강의실을 빠르게 탐색할 수 있도록 돕는 서비스입니다.  
단국대학교 강의 시간표 데이터를 기반으로 현재 시각에 사용 가능한 강의실을 계산하여 강의실을 추천합니다.
### 2. 주요 기능
* 홈
  * 프로필 및 선호 설정 수정
  * 최근 조회 강의실 확인
* 검색
  * 사용 가능 시간, 건물, 콘센트 여부로 필터링하여 빈 강의실을 탐색
  * 선호 설정을 통해 검색 설정 자동화
* 지도
  * 캠퍼스 지도에서 건물을 선택하여 건물 층별 평면도 확인
  * 층별 평면도 및 층별 강의실 확인
* 즐겨찾기
  * 강의실 카드 우상단 별표로 츨겨찾기
  * 즐겨찾기 된 강의실 목록 확인

# :information_desk_person: 비었곰 사용자 가이드
### 1. 시작하기
* 회원가입
  * 초기 사용자는 회원가입 클릭 시 회원가입 페이지로 이동하여 회원가입을 진행합니다.
  * 아이디, 비밀번호, 닉네임, 학번, 학과 입력 후 회원가입을 마칩니다.
* 로그인
  * 아이디와 비밀번호 입력 후 로그인합니다.

### 2. 강의실
* 강의실 카드
  * 건물 + 강의실 번호, 사용 가능 시간, 콘센트 여부, 다음 수업 정보, 즐겨찾기 버튼으로 구성됩니다.
  * 사용 가능 시간은 남은 시간에 따라 색상이 변경됩니다.
  * 사용 가능 시간은 현재 시간 기준으로 계산되며 09~22시 범위로 제한됩니다.
* 강의실 상세 보기
  * 강의실 카드 정보가 상단에 위치합니다.
  * 리뷰 총합과 리뷰 전체 보기 버튼이 위치합니다.
  * 해당 강의실의 월~금 강의 시간표가 그래픽으로 표시됩니다.
  * 요일 - 교시 표로 표시되며 강의명, 강의시간, 교수명이 표시됩니다.
* 리뷰
  * 리뷰 전체 보기 버튼으로 전체 리뷰를 확인할 수 있습니다.
  * 내 리뷰와 전체 리뷰로 구분되어 표시하며, 리뷰 작성 및 삭제가 가능합니다.
  * 전체 리뷰는 다른 사용자의 닉네임과 선택한 리뷰 태크를 표시합니다.

### 3. 홈
* 프로필
  * 프로필 정보 : 회원가입 시 입력한 닉네임, 학번, 학과 표기됩니다.
  * 선호 설정 : 선호하는 검색 설정(선호 건물, 선호 시간, 콘센트 여부)을 수정하고 저장합니다.
  * 로그아웃 : 로그인 상태를 해제하고 로그인 페이지로 이동합니다.

* 최근 조회한 강의실
  * 최근 상세 정보를 조회한 강의실 3개의 강의실, 다음 수업 정보, 사용 가능 시간만을 간결하게 표시합니다.

### 4. 검색
* 검색
  * 사용 가능 시간, 건물, 콘센트 여부를 선택 후 검색합니다.(선호 설정 시 자동 입력)
  * 검색 조건에 부합하는 강의실이 검색 결과로 표시되고 클릭 시 강의실 상세 보기로 이동합니다.
  * 검색 결과는 추천 알고리즘을 통해 정렬됩니다.

### 5. 지도
* 캠퍼스 지도
  * 캠퍼스 지도와 건물을 마커로 표시합니다.
  * 마커 클릭 시 층별 평면도로 이동합니다.
* 층별 평면도
  * 건물 층별 평면도와 층별 강의실을 표시합니다.

### 6. 즐겨찾기
* 즐겨찾기 목록
  * 사용자가 즐겨찾기 한 강의실이 목록으로 표시됩니다.
  * 강의실 카드 우상단 별 모양 즐겨찾기 버튼으로 추가, 삭제할 수 있습니다.
